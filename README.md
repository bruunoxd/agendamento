## App de Agendamento de Cabeleireiro

Um aplicativo moderno e intuitivo para agendamentos de serviços de cabeleireiro e barbearia. Ideal para profissionais e clientes que buscam praticidade, organização e uma melhor experiência.

## 📱 Funcionalidades

- Cadastro e login de clientes e profissionais
- Agendamento de horários disponíveis
- Confirmação e cancelamento de agendamentos
- Histórico de atendimentos
- Painel administrativo para gerenciamento de serviços e horários

## 🛠️ Tecnologias Utilizadas

- **Frontend**: FlutterFlow
- **Banco de Dados**: Firebase
- **Autenticação**: Firebase Auth

## 🚀 Como Rodar o Projeto

- Emulador Android/iOS ou dispositivo físico
- Conta no Firebase (caso use)
- Conta FlutterFlow
